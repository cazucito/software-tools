DataGrip nació en 2015 como el IDE de bases de datos de JetBrains: SQL tratado con las mismas herramientas que un lenguaje de programación — autocompletado contextual, navegación entre tablas y columnas, refactorización.

## De SQL Developer a DataGrip

Oracle SQL Developer fue durante años la puerta oficial — y gratuita — al mundo de las bases de datos Oracle. DataGrip llegó desde otra filosofía: no pertenecer a ningún motor, sino entenderlos a todos (Oracle, MySQL, PostgreSQL y compañía) desde un mismo entorno.

## Contexto personal

Llegó en 2018, cuando ya vivía en IntelliJ y la consistencia entre herramientas pesó más que la costumbre. Escribir SQL con la misma comodidad con la que escribía Java fue el cambio de era: la base de datos dejó de ser una terminal aparte y se volvió parte del proyecto.
