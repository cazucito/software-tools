Microsoft Access apareció en 1992 como la base de datos de escritorio de Office: tablas, consultas, formularios e informes en un solo paquete, sin servidor y sin administración.

## La puerta de entrada a las bases de datos

Para quien venía de las hojas de cálculo, Access era la graduación natural: del papel cuadriculado a las relaciones entre tablas. Su motor Jet permitía construir aplicaciones de datos completas en una tarde, y su integración con Visual Basic lo volvió una pieza clave del desarrollo rápido de los 90s.

## Contexto personal

Fue mi primera base de datos «de verdad», en la época en que el combo Access + VB6 era el estándar de facto para herramientas internas y aplicaciones de gestión en pequeña escala. Después vendrían los motores empresariales, pero el modelo relacional lo entendí primero aquí, con formularios dibujados a mano.
