# .agents/ — continuidad para agentes

Este directorio da contexto a agentes de IA entre sesiones (patrón del ecosistema kofro). Los documentos rectores del proyecto viven en [`docs/`](../docs/README.md) y [`AGENTS.md`](../AGENTS.md).

| Archivo | Qué contiene |
|---|---|
| [CONTEXT.md](CONTEXT.md) | Foto del proyecto: qué es, estado, arquitectura en 1 página |
| [STATE.md](STATE.md) | Fase actual, entregado, pendiente |
| [HANDOFF.md](HANDOFF.md) | Cómo continuar: siguiente fase, recetas, cuidados |
| [MEMORY.md](MEMORY.md) | Lecciones y peculiaridades de este repo (para no re-tropezar) |

Regla: mantenerlos **cortos** y al día al cerrar cada fase.
