Atom apareció en febrero de 2014 como el editor de GitHub: construido con tecnologías web (Electron, antes de que Electron tuviera nombre), gratuito y — su promesa central — totalmente hackeable. Hasta el CSS del editor podía reescribirse desde la preferencias.

## La promesa hackeable

La idea era que cada usuario moldeara su editor: paquetes en JavaScript, temas intercambiables, una comunidad abierta. En la práctica, tanta libertad tenía un costo: el rendimiento. Atom era hermoso y poderoso, pero cargaba la mochila de un navegador completo.

## Contexto personal

Lo probé en la época en que los editores modernos se disputaban el escritorio, como parte de la transición Sublime → Atom → VS Code. Atom abrió la puerta que VS Code atravesó después: la lección de que las herramientas web podían ser herramientas serias — si lograban ser rápidas.

## El cierre

GitHub archivó Atom en diciembre de 2022. Su código sigue disponible — la historia de los editores le debe, al menos, el experimento.
