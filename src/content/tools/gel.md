GEL fue un IDE de Java compilado de forma nativa para Windows, publicado por el equipo de GExperts (el conocido paquete de herramientas para Delphi). A diferencia de los IDEs basados en la JVM de la época, corría como ejecutable nativo (`.exe`), lo que lo hacía notablemente ligero y rápido de arrancar.

## Qué ofrecía

- **Code completion**: autocompletado de código Java
- **Parameter hints**: ayuda contextual de parámetros de métodos
- **Context-sensitive help**: ayuda sensible al contexto
- **Smart project management**: gestión de proyectos integrada
- **GelDic**: utilidad de diccionario para el editor
- **Plug-ins**: FTP (GelFtp), generación de JARs (JarMaker), formato de código y análisis estático con PMD (PDM05)

## Distribución y conservación

GEL se distribuía como **freeware** desde el sitio de GExperts (gexperts.com), hoy inactivo. El proyecto se conserva en el **Internet Archive** en la Tucows Software Library (donación de Tucows Inc.), lo que permite recuperarlo y verificarlo décadas después.

## Presencia en esta colección

Se conserva la serie de ejecutables de release candidates (GelRC32c → GelRC40) y los plug-ins de la instalación, verificados byte-a-byte en el servidor. La referencia pública al instalador oficial (Gel 8.6a) está en el Internet Archive.
